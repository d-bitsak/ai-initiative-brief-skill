# Примеры

## kp-assistant — ИИ-ассистент по подготовке коммерческих предложений

Сквозной пример работы навыка: от транскрипта интервью до готового документа.

| Файл | Что это |
| --- | --- |
| [transcript.md](kp-assistant/transcript.md) | Вход: транскрипт discovery-интервью с заказчиком |
| [brief_filled.md](kp-assistant/brief_filled.md) | Промежуточный результат: бриф в markdown по структуре шаблона |
| `Бриф на ИИ-инициативу — ИИ-ассистент по подготовке КП.docx` | Выход: итоговый Word-документ |

**Компания, люди, системы и цифры вымышлены** — пример существует для демонстрации формата и уровня детализации.

### Что в этом примере стоит посмотреть

**Как работает граница «факт из транскрипта» vs «ответ на уточняющий вопрос».** Из интервью пришли контекст, идея, проблемы, цели, сценарии, ограничения и источники данных — всё это заказчик проговорил сам. А вот раздел «Измеримые цели» в интервью не прозвучал: на прямой вопрос о цифрах заказчик ответил «надо поднимать статистику». Даты и полные ФИО участников тоже не назывались. Всё это — результат Шага 4, когда навык собрал один список уточняющих вопросов и достроил бриф после ответов. Именно так это и должно выглядеть: в транскрипте цифр нет, но в брифе они появились не из воздуха.

**Как формулируются проблемы.** Каждый пункт — наблюдаемый негативный эффект с фактурой из интервью («два рабочих дня», «считают по скачанной копии прайса», «на сопоставимых объёмах условия различаются в полтора раза»), а не отсутствие фичи. Пожелания заказчика («хочу, чтобы показывал, откуда взял цену») ушли в «Идею» и «Ограничения», а не в проблемы.

**Как выглядят SMART-цели.** Каждая — с базовым значением, целевым и сроком. Если бы заказчик не назвал базовые цифры, на их месте стояла бы пометка «требует уточнения», а не правдоподобная выдумка.

**Как заполняются «Сроки» и «Проектная группа».** Три даты (начало, MVP на ограниченной группе, масштабирование на весь периметр) и роли со стороны заказчика, включая владельца портфеля — того, кто определяет проект, формирует команду и задаёт рамки, но не участвует в ежедневной работе.

### Как повторить

Положите `transcript.md` в рабочую папку и попросите Claude собрать бриф. Навык задаст те же уточняющие вопросы — по цифрам, датам и составу группы. Ответы можно взять из готового брифа, чтобы сравнить результат с эталоном.
